# ReStorAI: Parampara 3D Reconstruction 🏛️✨

An advanced AI-powered web application built for the **Smart India Hackathon (SIH) 2026**. ReStorAI digitally reconstructs and revitalizes damaged or incomplete images of traditional Indian heritage sites and artwork, bringing history back to life.

## 🚀 Key Features
* **AI Image Reconstruction:** Utilizes the Pollinations AI API to intelligently fill in missing or damaged parts of heritage images.
* **Modern Tech Stack:** Built with a blazing-fast Next.js frontend and TypeScript for robust, error-free code.
* **Seamless UI/UX:** A clean, responsive interface designed with Tailwind CSS, allowing users to easily upload images and view reconstructed results.
* **Instant Processing:** Real-time feedback and fast image generation.

## 💻 Technology Stack
* **Frontend Framework:** Next.js (React)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **AI Integration:** Pollinations AI API

## 📂 Project Structure
* `app/` - Contains the main Next.js application routing and pages (`page.tsx`, `layout.tsx`).
* `components/` - Reusable UI components (e.g., Image Uploader, Result View).
* `lib/` - Utility functions and API integration logic.
* `public/` - Static assets and icons.
